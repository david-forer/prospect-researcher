# How I write

Copy this file to `voice.md` and replace the example with your own.

- Sign emails: Sam
- Direct and specific. Short sentences. Plain words.
- Write for a US reader.
- Never use: em dashes, semicolons, exclamation marks
- Never say: "I came across", "hope this finds you well", "game-changer", "leverage", "unlock"
- No flattery before the point. Lead with what I noticed about them.
